# Cybersecurity Applied Skills

This document defines applied cybersecurity skills for the wider `lippytm` AI and computer science education ecosystem.

## Purpose
Make cybersecurity an essential everyday skill across coding, automation, AI systems, machine learning workflows, mixed environments, and builder self-improvement.

## Core Skill Areas

### 1. Secure Coding Skills
Topics:
- validating assumptions
- handling secrets safely
- safer dependency habits
- explicit permissions and boundaries
- reviewing code for risk as well as function

### 2. Environment Skills
Topics:
- setup hygiene
- separating experiments from production
- safer credential handling
- backup and recovery habits
- environment documentation

### 3. Workflow Security Skills
Topics:
- review before execution
- scoped automation
- safer defaults
- logging and traceability
- human checkpoints for risky steps

### 4. AI and ML Security Skills
Topics:
- data handling caution
- prompt and workflow boundaries
- evaluation before wider reuse
- documenting failure cases
- separating research from operational systems

### 5. Builder Review Skills
Topics:
- reflection checklists
- architecture review habits
- incident notes
- lessons learned documentation
- improving future patterns from failures

## Best Practices
- teach security inside every lesson
- make risk review part of development
- keep examples small, explicit, and reusable
- document boundaries clearly
- include failure cases in educational material
