# Track 1 — Upland

## Purpose

Build AI-powered companion businesses around Upland property ownership, neighborhoods, decor, services, and portfolio operations.

## Business Lines

### Upland Property Fleet Bot
- classify holdings as hold, build, decorate, sell, or cluster
- score neighborhood concentration
- identify underperforming properties
- create next-action plans

### RoboDecor Bot
- recommend themes and ornament/decor placement
- generate district style packs
- draft storefront and listing copy
- support seasonal campaigns

### Upland Realtor Robot
- buyer guidance by budget, city, and style
- seller support and portfolio packaging
- collection and district narrative positioning

## Data Model

- property_name_or_address
- city
- neighborhood
- collection_status
- structure_status
- decor_status
- strategic_role
- notes

## MVP

1. property intake form
2. scoring rules engine
3. recommendation API
4. themed dashboard
5. report export

## Revenue Ideas

- premium portfolio review
- district design service
- decor strategy packs
- chatbot guidance for buyers/sellers
