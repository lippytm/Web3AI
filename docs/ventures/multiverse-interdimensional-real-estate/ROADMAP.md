# Roadmap

## Phase 1 — Strategy Installation
- define the four venture tracks
- define bot roles and guardrails
- align repo structure and project language

## Phase 2 — Data & Rules
- create intake schemas for properties, parcels, and worlds
- define scoring rules and recommendations
- create prompt templates and report formats

## Phase 3 — API Layer
- add FastAPI endpoints for intake, scoring, and content generation
- add adapters for manual data entry and CSV import
- expose internal JSON schemas for frontend use

## Phase 4 — Frontend Layer
- holdings dashboard
- chatbot concierge UI
- themed landing pages for each track
- reports and recommendation views

## Phase 5 — Expansion
- ManyChat/BotBuilders integration
- educational products and lead funnels
- district launch kits
- off-world lore and franchise products
