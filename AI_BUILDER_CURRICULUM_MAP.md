# AI Builder Curriculum Map

This document defines a broad and flexible curriculum map for AI builders inside the wider `lippytm` ecosystem.

## Purpose
Create a practical learning structure that supports AI development, computer science foundations, programming languages, libraries, machine learning tools, workflow systems, and applied builder growth.

## Core Principle
Teach broadly, build practically, document clearly, and allow multiple paths through the same ecosystem.

## Major Learning Domains

### 1. Computer Science Foundations
Topics:
- logic and problem solving
- data structures and algorithms
- operating systems concepts
- networking basics
- software engineering habits
- debugging and testing

### 2. Programming Languages
Topics:
- Python
- JavaScript / TypeScript
- shell and command-line basics
- SQL fundamentals
- optional Linux-first tooling
- mixed-environment development habits

### 3. Libraries and Tooling
Topics:
- standard libraries
- HTTP and API tooling
- data processing libraries
- visualization libraries
- automation libraries
- version control and repo tooling

### 4. Machine Learning and AI Libraries
Topics:
- model APIs
- prompt engineering
- embeddings and retrieval concepts
- ML workflow basics
- evaluation habits
- agent and orchestration patterns

### 5. Workflow and Agent Systems
Topics:
- workflow design
- routing patterns
- evaluation loops
- documentation-first experimentation
- safe human review points

### 6. Applied Builder Tracks
Topics:
- educational applications
- automation systems
- internal ops systems
- chatbot systems
- blockchain and Web3 systems
- productization and reusable kits

## Teaching Pattern
1. explain the concept
2. show a minimal example
3. build a repo-based exercise
4. reflect on what worked and failed
5. convert the lesson into a reusable pattern

## Connected Repositories

## Guiding Principle
A complete AI builder education system should support many languages, many libraries, many environments, and many creative pathways without losing structure.
